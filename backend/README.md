# Backend

FastAPI обслуживает API и production-сборку интерфейса. Запускайте команды из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
.\.venv\Scripts\python.exe -m pytest backend/tests -q
```

Полный актуальный контракт OpenAPI доступен на `/docs`. Основные сущности: аккаунты, организации, пространства, планы, навигационный граф и медиа.

| Настройка | Назначение |
|---|---|
| `SPACE_DB_PATH` | Путь SQLite; по умолчанию `backend/data/space.db` |
| `SPACE_ADMIN_PASSWORD` | Пароль организатора демонстрационного проекта |
| `SPACE_ALLOWED_ORIGINS` | Дополнительные разрешённые origin через запятую |

Без заданного пароля сервер создаёт случайное значение рядом с БД в `admin-password.txt`. Секреты и данные не коммитятся. Для собственных пространств используются аккаунты и серверные ACL. Сохранение черновика не публикует карту. Запрос с устаревшей ревизией получает 409.

Сшивка фотографий рассчитана на один worker. Нельзя запускать тесты на пользовательской базе. pytest и Playwright создают изолированные данные.

Перед коммерческим развёртыванием остаются подтверждение email, восстановление доступа, дисковые квоты, журнал аудита и общие лимиты запросов для нескольких процессов. Дополнительные сведения: [архитектура](../ARCHITECTURE.md), [развёртывание](../deploy/README.md).
