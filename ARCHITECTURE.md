# Архитектура

## Компоненты

React/TypeScript хранит редактируемый план и отображает SVG-карту, объёмный обзор и панорамы Pannellum. FastAPI обслуживает API и собранный интерфейс с одного origin. SQLite хранит аккаунты, доступы, черновики и опубликованные снимки. Изображения хранятся в файловой системе и связаны с пространством.

## Данные и маршруты

Координаты относятся к этажу, а не к экранным пикселям. `metersPerUnit` задаёт масштаб. Навигационный граф содержит узлы и явные рёбра: обычный проход, лестницу или лифт. Dijkstra учитывает направление, закрытые рёбра и доступность. Межэтажный переход имеет явно заданные тип и длину. Отображение не подменяет вычисленный путь прямой линией между местами.

## Сохранение и публикация

Запрос изменения содержит ревизию. SQLite атомарно проверяет её и сохраняет следующую версию; конфликт возвращает HTTP 409. Публикация создаёт отдельный снимок сохранённой карты. Публичный viewer получает опубликованные данные, даже когда открыт под сессией владельца.

## Доступ

Аккаунты входят в организации с ролями owner/admin/editor/viewer. Сервер проверяет доступ к черновикам, изменению, публикации, медиа и заданиям обработки. Cookie-сессии используют HttpOnly; изменяющие запросы проверяют Origin. Скрытые кнопки не участвуют в принятии решения о доступе.

## Панорамы и LiDAR

OpenCV выполняет сшивку фотографий в серверном процессе. Рабочий запуск рассчитан на один worker. Частичная панорама сохраняет FOV и смещения, вместо растяжения на полную сферу. RoomPlan работает в нативном iOS-клиенте; веб-клиент принимает контракт JSON и готовит подложку. Скан не становится автоматически проверенным навигационным графом.

## Развёртывание

Docker Compose запускает приложение и Caddy. База и медиа находятся в постоянном каталоге данных. Резервное копирование использует SQLite backup API. Горизонтальное масштабирование, общая очередь и распределённый limiter потребуют изменения инфраструктуры.
