# Мобильный сайт и нативные приложения

25.10.2026. Один React-интерфейс и FastAPI API используются браузером, PWA и нативными оболочками. Оболочка загружает HTTPS-сервис, поэтому исправления сайта не требуют пересборки APK. Это приложение с WebView, а не переписанный на нативные виджеты редактор. Интернет нужен для актуальной карты, входа, сохранения и сшивки. Автономный просмотр — отдельный HTML-экспорт.

## Android

Готовый демонстрационный пакет: `artifacts/space-map-demo.apk`, Android 8.0+ (API 26). Он открывает `https://vladikgolosnoi.ru/map/demo`, имеет значок/экран приложения, возврат назад, повторную загрузку, переход в браузер, системный выбор файлов и вызов камеры. JSON и HTML передаются в системное окно сохранения порциями с лимитом 96 МБ. Каждый кадр камеры хранится в отдельном временном файле. LiDAR RoomPlan доступен только в iOS-коде.

Для установки перенесите APK на Android, откройте файл и разрешите установку из выбранного источника. APK подписан локальным демонстрационным ключом, имеет `debuggable=true` и не предназначен для публикации в магазине. Перед распространением релиза нужны собственная release-подпись, отключение debugging и приёмка на устройствах. Сборка и проверка подписи пройдены. Установка/запуск, камера, системное сохранение и поведение клавиатуры в Android **пока не проверены**: подключённого телефона нет, эмулятор не запускается без драйвера аппаратного ускорения.

Сборка на Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Нужны JDK (по умолчанию Android Studio `jbr`), Android SDK Platform 36.1 и Build Tools 36.1.0. Пути переопределяются `-Java` и `-Sdk`. Gradle/сетевые npm-зависимости не требуются. Скрипт компилирует Java, DEX и ресурсы, выравнивает APK, подписывает и проверяет подпись. Рабочие файлы находятся в `%TEMP%/space-map-android`, ключ — в исключённом из Git `tmp/android-signing`. Не удаляйте ключ, если нужно устанавливать обновления поверх прежнего APK.

Для отдельного эмуляторного стенда `-LocalTest` собирает `space-map-local-test.apk` с адресом `http://10.0.2.2:8012`; только в этом варианте разрешён HTTP. Используйте отдельную тестовую SQLite, а не пользовательские данные. Не распространяйте local-test пакет как публичное приложение.

WebView допускает навигацию/сетевые ресурсы своего origin; внешние HTTPS-ссылки открываются браузером. Нет отключения проверки TLS, доступа к произвольным локальным файлам или встроенного пароля. Организатор входит обычной серверной сессией. JavaScript-мост служит только для экспорта Blob в выбранный пользователем документ.

## iOS: карта и LiDAR в одном проекте

`ios/SpaceMapLiDAR.xcodeproj` содержит вкладки «Карта» (WKWebView) и «LiDAR» (Apple RoomPlan). Карта использует серверную сессию и системный выбор фотографий; загрузки через WKDownload передаются в меню «Поделиться». Подготовлены AppIcon, запрос камеры, обработка ошибок сети и подтверждение перезагрузки при возможных несохранённых изменениях.

Для установки нужен Mac с Xcode, выбранная команда подписи и iPhone/iPad. Проект ориентирован на iOS 17+. В Windows он **не собран**, IPA отсутствует; наличие Swift-файлов не означает готовность к установке. На обычном iPhone 13 работает веб-карта; этот телефон не имеет LiDAR. После сборки на совместимом Pro/iPad нужно отдельно принять RoomPlan, импорт JSON, сохранение файлов и скан нескольких комнат. Подробности — `ios/RoomPlanCompanion/README.md` и `docs/LIDAR_ROOMPLAN.md`.

## Что проверять перед показом с телефона

1. Вход, карта, поиск и маршрут на обоих этажах; поворот экрана, клавиатура, потеря/возврат сети.
2. Редактор: «Инструменты» → комната/узел/декорация → точка на плане → «Объекты» → свойства, перенос/удаление; сохранение, повторное открытие и публикация.
3. 3D → 2D, предпросмотр, прокрутка плана по обеим осям, масштаб карты двумя пальцами.
4. Выбрать несколько фото и сделать два отдельных кадра камерой. Убедиться, что это разные кадры, и запустить сшивку.
5. Экспортировать JSON и HTML через системное окно. Открыть выбранный файл и проверить содержимое; отдельно проверить автономный HTML на целевом устройстве.
6. iOS: отказ LiDAR на неподдерживаемой модели; на поддерживаемой — скан, возврат между вкладками, экспорт, импорт и контрольные измерения.

Мобильная раскладка и контракт Android-моста проверяются Playwright на настоящем Chromium с отдельной базой. Это не заменяет OS-проверки и Safari. Текущий APK открывает развернутый сайт: локальная мобильная доработка появится в нём после обновления веб-сервера.
