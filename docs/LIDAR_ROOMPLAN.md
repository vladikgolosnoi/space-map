# LiDAR / Apple RoomPlan

## Пользовательский путь

У браузера нет публичного Safari API для RoomPlan, поэтому измерение выполняет native iOS companion; веб остаётся редактором карты.

1. На поддерживаемом LiDAR iPhone/iPad Pro запустить `ios/SpaceMapLiDAR.xcodeproj`.
2. Снять комнату в встроенном RoomPlan интерфейсе, остановить скан и осмотреть обработанную 3D-модель.
3. Не закрывая приложение и не прерывая AR-сессию, при необходимости перейти к следующей комнате. Companion объединяет завершённые комнаты через `StructureBuilder`; несовместимые координаты дают ошибку с подсказкой переснять, не создавать видимость готового здания.
4. Экспортировать `.json` и `.usdz`: измерения для импорта/проверки в редакторе и модель для системного Quick Look.
5. В редакторе выбрать этаж и загрузить JSON. Проверить число комнат, габариты, этажи, количество измеренных элементов, уверенность и превью. Применение заменяет подложку текущего этажа.
6. Вручную совместить подложку с планом этажа, пройтись по стенам/проёмам на объекте и нарисовать узлы/рёбра доступного графа. RoomPlan не является источником графа и автоматически не гарантирует доступность проходов.

## Формат импорта

Версионированный JSON `space-map-roomplan` v1, `unit: m`. Обязательны `rooms[]`, идентификаторы, стены с точками начала/конца и confidence. Поддерживаются двери/окна/проёмы, `story`, высота стены и предметы с категорией, центром, bounding-box размерами и confidence. `source` и время съёмки несут происхождение. Лимиты на размер, массивы, координаты, finite числа и confidence выполняются клиентом до растеризации. Старый v1 экспорт только со стенами/проёмами остаётся допустимым.

Предпросмотр рисует измеренные поверхности и схематические footprint предметов. Итоговая подложка вписывается в габарит этажа; масштаб/положение нужно совместить оператору. Растровая подложка сама по себе не становится настоящими редактируемыми стенами и не меняет топологию графа. Низкий confidence подсвечивается, но не блокирует осмотр.

## Принятые границы

- RoomPlan распознаёт только часть помещений и объектов; стекло, зеркала, тесные и загромождённые зоны могут дать неполный результат. Высота комнаты — средняя высота найденных стен, а не проверенная строительная характеристика.
- USDZ — отдельная 3D-модель RoomPlan, не карта сайта и не навигационный граф.
- Обычный iPhone 13 не имеет LiDAR. Нужна поддерживаемая модель Pro/Pro Max или iPad Pro. Для запуска native target нужен Mac/Xcode.
- Нативная Xcode-сборка ещё не принята; физический экспорт/импорт/сшивка комнат и контроль размеров не проверены. Playwright подтверждает только web intake на тестовом контрактном JSON.
- Не представлять синтетический JSON или «Атлас» как измеренный объект. Перед эксплуатацией требуется физическая проверка рулеткой и ручное утверждение карты.

## Проверка

- `npm run build` — пройден (web и offline сборки).
- `npm run test:e2e -- --grep "RoomPlan intake"` — пройден сквозной тест предосмотра и импорта контрактного JSON.
- `.venv/Scripts/python.exe -m pytest backend/tests -q` — **72 passed**, одно предупреждение deprecation.
- `npm run test:e2e` — полный проход **27 passed** до последнего изменения уровня импорта. После разделения этажей и негативного теста неверных размеров повторён RoomPlan intake: **1 passed**; тест включает два этажа и проверяет выбор слоя.
- Xcode build и реальный RoomPlan scan — недоступны в этой среде.
